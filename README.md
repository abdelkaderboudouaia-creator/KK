# Q-play

تطبيق يساعد الناس على إيجاد الألعاب التي تُلعب من حولهم والمشاركة فيها.  
An app that helps people find games being played around them and take part in them.

---

## 🚀 تشغيل كود Flutter أون لاين بدون تثبيت أي شيء

هل تريد تجربة كود Flutter دون الحاجة لتثبيت أي شيء على جهازك؟ إليك أفضل الأدوات المتاحة مجاناً:

### 1. 🎯 DartPad (الأداة الرسمية من Google)
- **الرابط:** [https://dartpad.dev](https://dartpad.dev)
- الأداة الرسمية من فريق Flutter/Dart
- تدعم كود Dart و Flutter مباشرةً في المتصفح
- يمكنك رؤية نتيجة الـ UI فوراً دون أي تثبيت
- تدعم مشاركة الكود عبر رابط

### 2. 🧪 FlutLab
- **الرابط:** [https://flutlab.io](https://flutlab.io)
- بيئة تطوير Flutter كاملة أون لاين
- تدعم مشاريع متعددة الملفات
- يمكنك بناء وتشغيل التطبيق مباشرةً من المتصفح

### 3. ☁️ GitHub Codespaces
- **الرابط:** [https://github.com/codespaces](https://github.com/codespaces)
- بيئة VS Code كاملة في المتصفح
- يمكنك تشغيل هذا المشروع مباشرةً من GitHub دون تثبيت أي شيء
- مجاني للاستخدام المحدود

### كيفية تشغيل هذا المشروع عبر GitHub Codespaces:
1. افتح صفحة هذا المستودع على GitHub
2. اضغط على زر **`Code`** الأخضر
3. اختر تبويب **`Codespaces`**
4. اضغط **`Create codespace on main`**
5. انتظر حتى تُحمَّل البيئة، ثم شغّل:
   ```bash
   flutter pub get
   flutter run -d web-server --web-port=8080
   ```
